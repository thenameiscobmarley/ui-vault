§ 01 — shaders.js

Shader backgrounds.

Each one renders on the GPU at low resolution, pauses off screen and shares a single WebGL context, so a page can hold dozens. Click one to load it above. On light themes most of them switch to a dark stage made from the theme's ink.

§ 02 — collections · uv-depth-*

3D in plain CSS.

Flip cards, spinning cubes, carousels, prisms, coins, orbits, exploded layers and isometric tiles, built with transforms only. Hover them. Copy gives you the markup and only the CSS it needs.

§ 03 — collections · uv-an-*

Motion, one class.

Ambient loops and hover reactions for any element: float, breathe, jello, heartbeat, 3D spin, blob morph, neon flicker and shine. They respect your theme's accent colours.

§ 04 — collections · uv-bd-*

Borders that spin.

Spinning gradients, comets, marching ants, corner brackets that grow, frames that draw themselves, gold and chrome bezels.

§ 06 — use it

Two lines, any section.

Shaders need core.js and shaders.js. The CSS pieces only need collections.css (or just the CSS you copy). Everything is MIT.

A shader behind a hero

<section data-uv-shader="aurora" data-speed="0.8">
  <h1>Your headline</h1>   <!-- stays on top -->
</section>

<script src="uivault/js/core.js"></script>
<script src="uivault/js/shaders.js"></script>

Options: data-speed, data-res (render scale, default 0.5), data-fps, data-colors="#accent,#accent2,#bg,#ink", data-mode="auto|dark|theme", data-still, data-no-pointer. On <body> it becomes a fixed full-page background.

From JavaScript

const v = UV.shaders.mount(el, { shader: "synthwave", speed: 1.2 });
v.set({ shader: "galaxy" });     // swap live
v.set({ colors: "#ff3d7f,#3dd6ff,#0b0b14,#fff" });
UV.shaders.pause();  UV.shaders.resume();
Object.keys(UV.shaders.list);       // all 44 names

3D, motion and borders: <div class="uv-an-float">, <div class="uv-bd-comet">, or the markup shown on a uv-depth-* tile. Want only what you picked? Add them in the Library and zip.

All effects are original and made for this library. Shaders fall back to a soft CSS gradient where WebGL is unavailable and show a still frame with reduced motion.
