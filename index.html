§ 01 — The API

Two files. No build step.

Components are classes, behaviours are data-uv attributes, themes are data-uv-theme. Load the whole bundle or only the modules you need. Everything else lives on window.UV: toasts, modals, a ⌘K palette, confetti, tilt, magnetic hover, scroll scenes and synthesized UI sounds.

Quick start Read the docs Download .zip 
<!-- that's the whole setup -->
<link rel="stylesheet" href="lib/uivault.css">
<script src="lib/uivault.js" defer></script>

<body data-uv-theme="neon">
  <button class="uv-btn uv-btn--grad"
          data-uv="magnetic ripple"
          data-uv-confetti>Ship it</button>

// or from JS
UV.toast("Saved!", { type: "success" });
UV.cmdk([{ label: "Theme", action: () => UV.theme("toggle") }]);
