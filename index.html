§ 00 — The library

Twelve themes, seventy effects, one API.

Modular CSS + JS: load the whole bundle or only the modules you need, then mix 12 themes (data-uv-theme) and 70+ effects (uv-fx-*) on any element. Use uivault.css for buttons, tabs, cards, glass, forms, rings, docks, marquees and backgrounds. Use uivault.js for toasts, modals, a ⌘K palette, confetti, tilt, magnetic hover, count-ups, typewriters, scroll reveals and synthesized UI sounds.

Quick start Download .zip Read the docs Browse the showcase uivault.css uivault.js 
<!-- that's the whole setup -->
<link rel="stylesheet" href="lib/uivault.css">
<script src="lib/uivault.js" defer></script>

<button class="uv-btn uv-btn--grad"
        data-uv="magnetic ripple"
        data-uv-confetti>Ship it</button>

// or from JS
UV.toast("Saved!", { type: "success" });
UV.cmdk([{ label: "Theme", action: () => UV.theme("toggle") }]);
