New — UI Vault library v2

Two files. 40+ components. Zero build step.

Use uivault.css for buttons, tabs, cards, glass, forms, rings, docks, marquees and backgrounds. Use uivault.js for toasts, modals, a ⌘K palette, confetti, tilt, magnetic hover, count-ups, typewriters, scroll reveals and synthesized UI sounds.
