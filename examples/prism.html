Is this a real product?
No. Prism is invented for this example. Every component on the page is real, though: it's all UI Vault.
Which part is the scroll animation?
The tall section above is a uv-pin with data-uv-scrub="pin". CSS reads --p to fly the pieces in; UV.scrub() switches the theme.
Will it run on a slow laptop?
Yes. Only transform and opacity animate, and the scroll handler writes one CSS variable per frame.
