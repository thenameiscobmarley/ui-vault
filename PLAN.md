# v5 — modular API (resume here)
Layout: lib/css/{core,components,fx,blocks}.css + lib/css/themes/<name>.css ; lib/js/{core,motion,feedback,forms,fx}.js
Bundles lib/uivault.css + lib/uivault.js + downloads/*.zip are GENERATED by `python3 tools/build.py` (run after any lib edit).
Themes scope with data-uv-theme="name" on ANY element (mix & match). FX are uv-fx-* mixin classes + data-uv-fx JS effects.
