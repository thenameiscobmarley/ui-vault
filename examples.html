How they work

One variable does the moving.

UI Vault turns the scroll position into a number from 0 to 1 and writes it to --p on the element. Use it in any CSS calc(). Only transform and opacity change, so the examples stay smooth on integrated graphics.

  • data-uv-scrub: 0 when the element enters, 1 when it leaves
  • ="center": reaches 1 at the middle of the screen
  • ="pin": for a tall .uv-pin scene that stays on screen
  • ="page": progress through the whole page
  • data-uv-velocity: scroll speed as --v
  • UV.scrub(el, p => …): the same value in JavaScript
<!-- a 300vh scene; the stage stays pinned while --p goes 0 → 1 -->
<section class="uv-pin" data-uv-scrub="pin" style="--len:300vh">
  <div class="uv-pin__stage">
    <h1 class="title">Lift off</h1>
  </div>
</section>

<style>
  .title { transform: translateY(calc(var(--p) * -80vh))
                     scale(calc(1 + var(--p))); }
</style>

<script>  // numbers come from the same value
  UV.scrub(scene, p => alt.textContent = Math.round(p * 400) + " km", "pin");
</script>
